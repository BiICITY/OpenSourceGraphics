# 에코 동굴: 방향 음파

매판 새로 생성되는 2D 동굴에서 빛 조각 3개를 모아 출구로 탈출하는 Windows/Python 게임입니다. 적 9명이 동굴 전역에 분산되어 통로를 따라 이동합니다. 음파는 벽을 열지만 적을 부릅니다.

## 실행

- Python 3.8 이상 설치
- Windows: `run_windows.bat` 실행 (처음에는 인터넷으로 의존성 설치). `uv`가 설치돼 있으면 자동 사용하고, 없으면 `python` 명령으로 가상환경을 만듭니다.
- 직접 실행:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe game.py
```

macOS/Linux: 가상환경을 만든 뒤 `pip install -r requirements.txt`, `python game.py`를 실행합니다. 재현 가능한 지도를 보려면 `python game.py --seed 42`, 창 없이 생성만 확인하려면 `python game.py --check --seed 42`를 사용합니다.

## 조작과 규칙

| 조작 | 효과 |
|---|---|
| WASD / 방향키 | 한 칸씩 이동 |
| Space만 | 원형 음파: 근처 벽을 열고 넓은 범위의 적을 유인 |
| 이동키를 누른 채 Space | 방향 음파: 앞으로 길게 열고 유인 범위가 좁음 |
| R | 새로운 동굴 생성 |
| Esc | 종료 |

음파는 **한 판에 총 3회**이며 조각을 모아도 충전되지 않습니다. 음파의 기본 시야 범위 안에 있던 적은 **1초 기절**합니다. 음파에 반응한 조각은 플레이어 주변의 화살표로 약 2.3초간 방향을 알려줍니다. 벽을 부수면 그 통로는 적도 사용합니다. 체력은 3칸입니다.

적과 플레이어의 **직선거리 6칸 이내**에 들어가면 적이 추적을 시작하고, 6칸 밖으로 나가면 즉시 추적을 멈춥니다. 추적 중에는 BFS로 현재 통로를 따라 플레이어까지의 최단거리를 계산하고, 그 거리가 가장 짧아지는 칸으로 이동합니다. 음파를 들은 적(넓은 음파 24칸, 방향 음파 12칸)은 소리가 났던 **고정 위치**를 잠깐 조사합니다. 플레이어가 6칸 밖으로 벗어나면 현재 위치를 계속 쫓지는 않습니다. 적 색은 추적 중 빨강, 소리 조사 중 주황, 평상시 보라입니다. 초기 적 위치는 다른 적과의 최소 직선거리를 최대화하는 방식으로 골라 맵 전체에 퍼뜨립니다.

## 2D 원리와 오픈소스 사용

맵은 50×32개의 2D 격자입니다. 먼저 growing-tree 방식으로 시작점과 연결된 통로를 만듭니다. 그 후 OpenSimplex가 각 `(x, y)`에 부여하는 연속적인 노이즈 값 `n(x,y)`를 이용해 동굴 주머니를 열고 벽의 색 및 붕괴 확률을 바꿉니다. 임의 난수만 쓰면 주변 칸과 무관하게 값이 튀지만, 노이즈는 가까운 좌표의 값이 비슷하여 덩어리 모양이 나타납니다. 화면은 Pygame의 사각형, 선, 원, 다각형 드로잉으로 그립니다. 화면 좌표는 `pixel_x = tile_x × 22`, `pixel_y = tile_y × 22`입니다.

`game.py`의 `new_cave()`와 `echo()`를 보면 오픈소스 출력값을 게임 규칙에 연결한 부분이 나옵니다. `OSS_LINKS.txt`에 저장소, 사용 기능, 라이선스를 기록했습니다. 라이브러리 원본 코드는 변경하지 않았습니다. 게임 규칙, 맵 결합 방식, 적 추적, UI, 그리기는 이 프로젝트 코드입니다.

`oss_examples.py`를 실행하면 오픈소스 확인용 결과 3개가 `examples/`에 생성됩니다. ① Pygame의 사각형·원·다각형·선, ② OpenSimplex 연속 노이즈, ③ 같은 노이즈에 임계값을 적용한 지형 마스크입니다. 이 세 결과를 비교한 뒤 ③을 동굴 벽 생성에 결합했습니다.

## 원형 프로토타입과 바뀐 점

이 프로젝트 전에는 브라우저 Canvas 버전으로 아이디어를 시험했습니다. 제출 프로젝트는 Python/Pygame 창으로 새로 구현했습니다. 방향 음파/넓은 음파 선택, 음파 3회 제한, OpenSimplex 기반 지형 질감과 벽 반응, 시드 재현, 조각 방향 표시가 들어 있습니다.

## 과제 기록

AI 도구(Codex)를 사용해 아이디어 시제품, Python 포팅, 코드 구조, 설치와 테스트, 문서 초안을 만들었습니다. 과제 주제는 매번 구조가 바뀌는 맵에 게임 규칙을 더하고 싶다는 본인의 선택에서 시작했습니다. AI가 제안한 적 회피 규칙에 대해 본인이 미로형 장애물, 소리로 벽 허물기, 적 기절, 음파 횟수 제한, 적 수와 추적 범위 증가를 요청했습니다. 이후 적 9명의 분산 배치, 직선거리 6칸 이내 자동 추적과 범위 밖 추적 해제, 통로 최단거리 이동도 요청했습니다. 실제 소스 작성은 AI의 도움을 받았으며, 직접 키보드로 수정한 코드가 있다면 제출 전에 그 내용을 기록해야 합니다. 과제의 원리 설명은 직접 값을 바꿔 확인하고 자신의 말로 발표하세요. `REPORT_DRAFT.pdf`는 편집용 초안입니다.
